# Roadmap

This document outlines the milestones and roadmap for Reponis. The project is organized into sprints focusing on vertical slices.

## Sprint 1
- Repository connection
- GitHub authentication
- Repository synchronization
- Store raw GitHub data

## Sprint 2
- Metric engine
- Cycle time
- Churn metrics
- Issue metrics

## Sprint 3
- Dashboard
- Repository overview
- Charts
- Weekly snapshots

## Sprint 4
- AI summaries
- Polish
- Testing
- Deployment
